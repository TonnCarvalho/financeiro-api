# Operação

Existem trés tipos de operações
1. Guardado
2. Rendimento
3. Resgatado
## 1. Guardado
O valor investido ou guardado, ele é somado junto ao valor bruto e liquido.

## 2. Rendimento
O rendimento bruto e liquido é uma subtração dos valores *bruto de hoje* menos o valor *bruto de ontem*, o valor liquido é a mesma coisa, valor *liquido de hoje* menos o valor *liquido de ontem*.
Fazendo essa subtração a sobra é o rendimento do dia.

## 3. Resgate
O resgate é abatido do *valor liquido*.
